# Banking-System
Built a production-ready full-stack Banking System using Spring Boot, React.js, and MySQL, featuring account management, secure fund transfers, transaction history tracking, and RESTful APIs. Implemented validation, exception handling, and responsive UI to simulate real-world banking operations.


# # 🏦 Banking System (Full Stack Application)

## 📌 Project Overview
This project is a full-stack Banking System developed using **Spring Boot (Backend)** and **React.js (Frontend)**. It simulates real-world banking operations such as account management, deposits, withdrawals, fund transfers, and transaction tracking.

---

## 🚀 Features

- 👤 Create Bank Account
- 💰 Deposit Money
- 💸 Withdraw Money
- 🔄 Transfer Funds Between Accounts
- 📜 View Transaction History
- ⚠️ Input Validation & Exception Handling
- 🌐 REST API Integration
- 🎨 Responsive UI using React

---

## 🛠️ Tech Stack

### 🔹 Frontend
- React.js
- HTML, CSS, JavaScript
- Axios (API calls)

### 🔹 Backend
- Java Spring Boot
- REST APIs
- MVC Architecture

### 🔹 Database
- MySQL

## ⚙️ Installation & Setup

### 🔹 Backend (Spring Boot)

1. Open project in IntelliJ
2. Configure MySQL in `application.properties`:


spring.datasource.url=jdbc:mysql://localhost:3306/banking_db
spring.datasource.username=root
spring.datasource.password=your_password



3. Run Spring Boot application

---

### 🔹 Frontend (React)

```bash
cd banking-frontend
npm install
npm start

Runs on: http://localhost:3000.
